```
연습 모드 → 모달(튜토리얼 / 자유 공원) → 출전 준비(이름 · 캐릭터, 배지 "자유 공원") → [공원 입장]
```

튜토리얼은 같은 흐름으로 `[튜토리얼 시작]` → `enterTutorial()`. 아래 "튜토리얼" 절 참고.

### 자유 공원이란

낮으로 고정된 공원을 여러 사람이 함께 거니는 휴게 공간입니다. **전투 요소가 전부 없습니다.**

| 항목 | 공원에서 |
|---|---|
| 피해 · 체력 · 목숨 | 없음 (`takeHit` 이 즉시 반환) |
| 타이머 · 웨이브 · 점수 · 랭킹 | 없음 (`step()` 의 타이머 · `checkWaveClear` · `tickSpawner` 게이트) |
| 발명이 | 등장하지 않음 |
| 좌클릭 발사 · Q 실드 · R 폭탄 | 막힘 |
| 이동 · 점프 · 질주 · 앉기 · **F 손짓** | 됨 (F 는 근접 스윙 모션만 — 맞을 대상이 없음) |
| 아이템 | 필드에서 숨김 |
| HUD | 미니맵 · 인원 칩 · 채팅만 남고 나머지는 `.hud.park` 로 숨김 |
| ESC | 일시정지 카드에 [게임으로 돌아가기] / **[공원 나가기]** (결과 화면 없음) |
| 하늘 | `dayHold=0` 으로 낮 고정, 나갈 때 `null` 로 되돌림 |

모드 플래그는 `MODE` 하나(`'battle' | 'park'`)이고 `isPark()` 로 판단합니다. 진입은 `enterPark()`, 퇴장은 `exitPark()`.

### 맵 전환 구조

전투 맵을 뜯어내지 않고 **두 월드를 같은 씬에 두고 보이는 쪽만 바꿉니다.**

- `mergeStaticMap` 직후 `scene.children.slice(DECOR_START)` 를 통째로 `arenaGroup` 에 담고, 그 시점의 `colliders` 를 `ARENA_COLL` 로 복사해 둡니다.
- 공원은 `buildPark()` 가 `PARK.group` 과 `PARK.coll` 을 만듭니다 (처음 입장할 때 한 번).
- `setWorld('park' | 'battle')` 이 그룹 visible, `colliders` 배열 내용, 미니맵 배경(`MM.cv=null` → `mmInit` 재실행)을 한 번에 바꿉니다. 전투 맵의 흙 바닥(`ground`)은 공원에서 따로 숨깁니다.
- 랜드마크 4채 · 하늘 · 해 · 구름은 두 월드가 공유합니다.

### N명 동시 입장 — 방장 없는 구조

협동과 달리 계산할 권위가 없습니다. **각자 자기 위치를 보내고, 서버가 모두의 위치를 한 묶음으로 돌려줍니다.**

```
클라 → 서버   {t:'park', name, char}          입장 (정원 차면 parkfull)
클라 → 서버   {t:'pk', d:[x,y,z,ry,swing]}     초당 10회 (PARK_HZ)
서버 → 모두   {t:'pks', p:[[id,name,char,x,y,z,ry,sw],…]}   초당 10회, 한 번 stringify 해서 N번 전송
클라 ↔ 서버   {t:'pc', m}  /  {t:'pc', id, name, m}          채팅 (60자, 0.5초 간격)
서버 → 모두   {t:'pj', id, name} / {t:'pl', id, name}         입장 · 퇴장 알림
클라 → 서버   {t:'unpark'}                                   퇴장 (끊기면 자동)
```

- 한 명당 (N−1)번 전달하는 대신 tick 마다 N번만 보냅니다. 20명이어도 **초당 200건**, 건당 약 0.8KB.
- 상한은 `server.js` 의 `PARK_MAX`(기본 20). 서버보다 **클라이언트가 그리는 아바타 수**가 먼저 한계가 되므로, 사양 낮은 PC 가 많으면 12~16 으로 낮추는 편이 안전합니다.
- 클라이언트는 `parkPeers`(id → 모델 · 모션 상태 · 이름표)로 그리고, 받은 좌표로 보간하며 `animEntity` 를 그대로 태웁니다. 손짓은 `atkT` 로 팔 스윙.
- 서버가 없거나 끊기면 **혼자 있는 공원**으로 그대로 진행됩니다(칩에 "오프라인").
- 협동 방에 들어가면 서버가 공원에서 자동으로 뺍니다. 공원에 있다가 로비로 가면 `hello` 를 다시 보내 이름을 갱신합니다.
- 연결돼 있는 동안 5분마다 `GET /api/ping` 을 보내 무료 인스턴스가 잠들지 않게 합니다.

## 튜토리얼

공원 맵을 그대로 쓰되(`setWorld('park')`), 혼자이고 서버에 붙지 않습니다. `MODE='tutorial'`, `isTutorial()`, `isTraining()`(공원 또는 튜토리얼).

### 흐름

```
연습 모드 → 튜토리얼 → 출전 준비(이름 · 캐릭터, 배지 "튜토리얼") → [튜토리얼 시작]
```

오른쪽 아래에 발명이(봉제 인형 얼굴을 오프스크린 렌더)가 말을 겁니다. 한 과제의 흐름은 항상

```
설명(입력 잠금, 타자 효과, Space · 클릭으로 넘김) → 직접 해 보기 → 칭찬 팝업(무작위) → 다음 과제
```

위 가운데에 `1 / 4 · 이동` 진행 칩, 말풍선 아래에 체크리스트가 있고 끝난 항목은 체크됩니다.

| 단계 | 과제 (순서대로) | 통과 조건 |
|---|---|---|
| 1 이동 | 걷기 → 점프 → 달리기 → 앉기 | 3.5m 이상 걷기 / 공중에 뜨기 / Shift 달리기 4m / Ctrl·C 0.5초 |
| 2 공격 | 발사 → 연사 → 근접 | 무한 체력 허수아비(1웨이브 발명이, `e.invincible`)를 1발 / 6발 이상 / F 로 때리기 |
| 3 약점 | 헤드샷 | 머리 판정(피해 2배) 1회 |
| 4 아이템 | 체력 → 이동속도 → 공격력 → 폭탄 | 체력 50 깎고 십자 줍기 / 운동화 줍고 14m 달리기(끝나면 "제자리로") / 검 줍고 허수아비 3타 / 앞쪽 부채꼴 허수아비 5마리를 폭탄 한 발로 |

폭탄에서 살아남은 허수아비가 있으면 폭탄을 다시 줍니다. 끝나면 "이제 가짜 발명이를 무찌르러 가볼까요?" → 일시정지 + 모달 **튜토리얼이 종료되었습니다** ([다시하기] / [메인으로 돌아가기]). ESC 는 일시정지 카드에 [게임으로 돌아가기] / [튜토리얼 나가기].

### 코드 위치

- 대본은 `STEPS` 배열 하나입니다. 과제마다 `{id, label, text, init, check, after, leave}` — 문구를 바꾸거나 과제를 넣고 빼려면 여기만 손대면 됩니다. 칭찬 문구는 `PRAISE`.
- 게임 쪽 훅: `tutEvent('hit'|'melee'|'pickup_*'|'bomb'|'dummyDead')` 가 `applyDamage` · `tryMelee` · `pickupItem` · `useBomb` 에서 불립니다. 허수아비는 `spawnDummy()` (`e.dummy` — AI 를 타지 않음).
- `.hud.tutmode` 로 점수 · 시간 · 웨이브 · 미니맵 등을 숨깁니다. 콘솔에서 `__tut()` 로 상태, `__tutGoto(n)` 으로 n번째 단계로 건너뜁니다.

## 랭킹 — GitHub 저장소에 커밋

무료 인스턴스는 재시작하면 디스크가 비므로, **GitHub 저장소의 CSV 한 장을 원본**으로 씁니다.

- 서버가 켜질 때 저장소에서 `scores.csv` 를 내려받아 로컬 캐시(`data/scores.csv`)로 둡니다.
- 새 기록이 들어오면 로컬에 바로 붙이고, `GH_DEBOUNCE_MS`(기본 15초) 동안 모았다가 **파일 전체를 한 커밋**으로 올립니다. 커밋 메시지 예: `랭킹: 홍길동 18,000점 (총 42건) [skip render]`.
- sha 가 어긋나면(다른 곳에서 파일을 고침) 원격 sha 만 다시 받아 한 번 재시도, 실패하면 1분 뒤 재시도. 종료 신호(SIGTERM)를 받으면 밀린 기록을 바로 올리고 꺼집니다.
- `GH_TOKEN` 이 없으면 예전처럼 로컬 CSV 만 씁니다 (부팅 시 지우지는 않음).

### Render 환경 변수

| 변수 | 값 |
|---|---|
| `GH_TOKEN` | GitHub **Fine-grained personal access token**. 해당 저장소만 선택, Repository permissions → **Contents: Read and write** (Metadata 는 자동으로 Read). 만료일을 길게. |
| `GH_REPO` | `소유자/저장소` 예: `ohda/patent-war-data` |
| `GH_PATH` | 저장소 안 경로 (기본 `data/scores.csv`). 파일이 없으면 첫 커밋에서 만듭니다. |
| `GH_BRANCH` | 기본 `main` |
| `GH_DEBOUNCE_MS` | 기본 `15000` |

게임 코드와 **같은 저장소**를 써도 됩니다 — 커밋 메시지의 `[skip render]` 덕분에 Render 가 다시 배포하지 않습니다. 다만 기록이 코드 커밋 사이에 섞이므로, 깔끔하게 두려면 데이터 전용 저장소를 하나 파는 편이 낫습니다(private 도 됩니다).

상태 확인: `GET /api/ranks/status` → `{github, repo, rows, pending, lastCommit, lastError}`. 토큰 권한이 모자라면 `lastError` 에 `GitHub PUT 403 …` 이 찍힙니다.

### CSV

```
timestamp,mode,name,partner,character,score,kills,wave,dur
```

`dur` = 플레이 시간(초, `MATCH_TIME − timeLeft`; 조기 클리어면 짧음). 예전 8열 파일도 그대로 읽고, 다음 커밋부터 새 헤더로 바뀝니다. `GET /api/ranks.csv` 로 내려받기.

### API

- `POST /api/scores` `{mode, name, partner, character, score, kills, wave, dur}` → `{ok, mode, rank, total}` — **같은 모드 안에서의** 순위(싱글은 싱글끼리, 협동은 협동끼리)
- `GET /api/ranks?mode=solo|coop|all&range=day|week|month|all&limit=50` → `{mode, range, total, ranks:[{rank, mode, name, partner, character, score, kills, wave, dur, ts}]}`. `mode` 를 빼면 합산. 일간·주간(월요일 시작)·월간 경계는 **한국 시간** 기준.

### 랭킹 화면

**좌측 싱글 · 우측 협동** 두 목록은 그대로 두고, 위쪽 **일간 / 주간 / 월간 / 전체** 탭 하나가 두 목록에 함께 걸립니다 — '주간'을 누르면 싱글 주간과 협동 주간이 나란히 나옵니다. 열: 순위 · 이름(협동은 `방장 & 동료`) · 웨이브 · 플레이(`3:00`) · 날짜(`09/28`) · 점수. 탭 오른쪽에 `이번 주 · 싱글 6개 · 협동 4팀 · 한국 시간` 식으로 건수를 적습니다. 결과 화면 순위도 같은 모드 안에서 매깁니다.

## 이번 변경 (3차)

### 1. Ctrl+W 등 실수 종료 막기

앉기가 `Ctrl`, 전진이 `W` 라서 **앉아 걷는 동안 그대로 `Ctrl+W`(탭 닫기)** 가 되어 버리던 문제. 세 겹으로 막습니다.

1. **키 단계** — 플레이 중(`gameState` 가 `playing`·`countdown`)이면 캡처 단계에서 `Ctrl/⌘ + W·N·T·R`, `F5`, `Ctrl/Alt+F4`, `Backspace`(본문에서), `Alt+←/→` 의 **브라우저 기본 동작만** 막습니다. 전파는 끊지 않으므로 앉아 걷기 · 앉아 폭탄(Ctrl+R) 같은 조작은 그대로 됩니다.
2. **확인창** — 크롬은 `Ctrl+W` 를 웹 페이지가 막을 수 없습니다. 그래서 플레이 중일 때만 `beforeunload` 로 "나가시겠습니까?" 를 띄워 한 번 더 붙잡습니다. 메뉴 · 일시정지 중에는 뜨지 않습니다.
3. **키보드 잠금** — 전체화면(F11)이면 `navigator.keyboard.lock()` 으로 조합 자체를 가로챕니다. 지원하지 않는 브라우저에서는 조용히 넘어가고, 커서 안전장치가 돌 때 같이 풉니다.

## 이번 변경 (6차) — 화면이 흰색으로 죽는 현상

전투 중 3D 화면만 아무 디테일 없는 단색(흰색)이 되고 HUD·타이머·미니맵은 멀쩡히 도는 현상.

### 원인

씬 상태 어딘가에 **NaN** 이 들어가면 지오메트리가 하나도 그려지지 않고 배경 클리어 색만 남습니다. 드라이버에 따라 NaN 이 1.0 으로 뭉개지면 흰색, 0 으로 뭉개지면 검정이 됩니다(소프트웨어 렌더러에서는 검정으로 재현).

한 번 들어온 NaN 이 **영구히 남는 지점**이 `applyDaylight` 였습니다.

```js
if(!force && Math.abs(t-dayApplied)<.0012) return;   // t 가 NaN 이면 언제나 false
```

조기 반환이 안 걸려 매 프레임 `scene.background` · `scene.fog` · 모든 광원에 NaN 을 다시 바릅니다. 값이 정상으로 돌아와도 복구되지 않습니다.

NaN 유입 경로로 확인된 곳은 협동 게스트의 월드 동기화입니다.

```js
wave=d.wv; waveKills=d.wk; timeLeft=d.tl; score=d.sc;   // 검증 없음
```

`d.tl` 이 한 번이라도 빠지면 `timeLeft` 가 `undefined` → 낮/밤 진행도가 NaN → 게스트 보간식 `dayT += (target-dayT)*k` 때문에 영구 NaN. 다음 패킷이 정상이어도 타이머만 돌아오고 하늘은 죽은 채 남습니다.

### 조치

1. **`applyDaylight` 입구 차단** — 유한값이 아니면 아무것도 하지 않습니다.
2. **`tickDaylight` 자가 복구** — `timeLeft`·`timeAcc` 가 깨졌으면 0 으로 되돌리고, `dayT` 가 이미 NaN 이면 현재 목표값으로 되살립니다.
3. **`applyWorld` 값 검증** — 호스트 패킷의 `wv`·`wk`·`tl`·`sc` 가 깨져 있으면 직전 값을 유지합니다.
4. **매 프레임 마지막 안전망** — 그리기 직전에 카메라 위치·회전과 배경·안개를 확인해, 깨져 있으면 마지막 정상값으로 되돌립니다. 원인을 못 잡아도 증상은 남지 않습니다.
5. **`webglcontextlost` / `restored` 처리** — 지금까지는 그래픽 컨텍스트가 날아가도 게임이 조용히 계속 돌아 화면만 죽은 채로 남았습니다. 이제 잠금을 풀고 일시정지한 뒤 상단에 안내를 띄우고, 복구되면 장면을 다시 칠합니다.

### 확인

고장을 일부러 주입해 증상이 재발하지 않는 것을 확인했습니다.

| 주입 | 결과 |
|---|---|
| `dayT`·`timeAcc` 에 NaN | 다음 프레임에 자가 복구, 배경 정상 |
| 카메라 위치·회전에 NaN | 다음 프레임에 자가 복구, 화면 정상 |
| 게스트 패킷에서 `tl` 누락 | `timeLeft` 가 직전 값(179) 유지 |
| WebGL 컨텍스트 강제 분실 | 안내 배너 표시 · 포인터 잠금 해제 · 커서 복귀 · 일시정지 |

전투 · 자유 공원 · 튜토리얼 · 랭킹 네 화면 모두 회귀 없음(콘솔 오류 0건).
